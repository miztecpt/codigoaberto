# CodigoAberto Toolbox

Protótipo visual de um site de ferramentas digitais com interface de backoffice e navegação lateral.

## Abrir a demonstração

Abra `index.html` num navegador. Não é necessário instalar dependências nem executar um processo de compilação.

## Ferramentas apresentadas

- Ping
- Meu IP
- DNS Lookup
- Traceroute
- IMAPSync
- Verificar SSL
- Diagnóstico de email
- Cabeçalhos de email
- Gerador de palavras-passe

## Estado do projeto

Esta versão é uma demonstração gráfica. Os resultados são simulados: não existem consultas reais de rede, ligações IMAP ou migrações de email. Não introduza credenciais reais nos formulários.

## Estrutura

- `index.html`: interface, estilos e interações da demonstração.
